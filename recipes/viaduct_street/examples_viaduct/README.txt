Example values from an elevated-road site (LichtFeld "out_fpv", 7206 images, 15M gaussians).
All lateral values are measured from the polynomial-smoothed route (straighten.py / build_v3.py), s = route arclength in 3DGS units.
Scale S = 1.6 m/unit (girder bottom 4.3, cap bottom 2.9, camera height 1.08 units).
These are a starting point for a similar scene, not defaults for a new one: re-measure everything per project.
